# Lemon UI

LemonDouble 디자인 시스템의 React 컴포넌트와 토큰입니다. 규칙과 그 이유는 [DESIGN.md](https://github.com/LemonDouble/lemon-ui/blob/main/DESIGN.md)에 있습니다.

## 설치

```bash
pnpm add @lemondouble/ui
```

사용하는 프로젝트는 Next.js 16 이상, React 19 이상, Tailwind CSS v4, lucide-react를 씁니다.

## 전역 CSS

```css
@import url("https://cdn.jsdelivr.net/npm/galmuri@2.40.3/dist/galmuri.css");
@import url("https://cdnjs.cloudflare.com/ajax/libs/pretendard/1.3.9/static/pretendard.min.css");
@import url("https://cdn.jsdelivr.net/npm/@fontsource-variable/jetbrains-mono@5.2.8/index.css");
@import "tailwindcss";
@import "@lemondouble/ui/theme.css";
```

- `theme.css`에 토큰(`@theme`), z-index 변수, 기본 스타일이 들어 있습니다. 토큰 블록을 프로젝트에 따로 복사하지 않습니다.
- `theme.css`가 패키지 폴더를 Tailwind 스캔 대상에 넣으므로, 컴포넌트의 클래스가 프로젝트 CSS에 함께 생성됩니다.

## 사용

```tsx
import { Button, Callout } from "@lemondouble/ui";

<Callout tone="warning">저장 공간이 90% 찼습니다.</Callout>
<Button>저장</Button>
```

## 입력 요소의 배경

입력 요소는 `--field-bg` 변수를 배경으로 씁니다. 페이지 위에서는 `surface`이고, `Card`, `Dialog`, `RowList` 안에서는 자동으로 `bg`가 되어 입력칸이 묻히지 않습니다. 직접 만든 surface 컨테이너에서는 `[--field-bg:var(--color-bg)]` 클래스를 붙입니다.
